# Data Transformation in Alteryx

This repository contains the hands-on exercises and workflows completed during the **Data Transformation in Alteryx** course on **DataCamp**. The exercises focus on transforming, reshaping, and aggregating data using core Alteryx Designer tools commonly used in data preparation and analytics workflows.

## 🎯 Learning Objectives

Throughout this course, I developed practical skills in:

- Building conditional logic using the **Formula Tool**
- Applying business rules with IF, ELSEIF, and IIF statements
- Using logical operators such as AND, OR, and NOT
- Working with string functions, including CONTAINS
- Using the Expression Editor to create calculated fields
- Transposing data from wide to long format
- Cross-tabbing data from long to wide format
- Aggregating and summarizing data
- Designing efficient data transformation workflows in Alteryx

## 🛠 Skills Gained

### Formula Tool
- Conditional statements (`IF`, `ELSEIF`, `IIF`)
- Logical operators (`AND`, `OR`, `NOT`)
- String functions (`CONTAINS`)
- Calculated fields

- Data pivoting (wide to long transformation)
- Configuration of Key Columns

### Cross Tab Tool
- Data unpivoting and restructuring

## 📂 Repository Tasks

### Task 1: Formula Tool

#### Objective
Apply business rules and create calculated fields using conditional expressions.

#### Key Concepts
- IF / ELSEIF statements
- IIF function
- AND, OR, NOT operators
- CONTAINS function
- Expression Editor

#### Outcome
Created transformation logic to classify, clean, and enrich data based on specified business conditions.

---

### Task 2: Transpose Tool

#### Objective
Convert data from a wide structure into a long structure for easier analysis.

#### Key Concepts
- Key Columns
- Data Columns
- Missing Columns
- Name and Value output fields

#### Outcome
Restructured datasets into a normalized format suitable for reporting and downstream transformations.

---

### Task 3: Cross Tab Tool

#### Objective
Transform and aggregate data into a summarized tabular format.

#### Key Concepts
- Group Data By
- Column Headers
- Values for New Columns
- Aggregation Methods

#### Outcome
Generated summarized datasets by pivoting rows into columns and applying aggregation logic.
